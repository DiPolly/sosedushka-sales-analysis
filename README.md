# sosedushka-sales-analysis
Кейс: Анализ продаж и эффективности сети продуктовых магазинов «Соседушка»

1. Задача
Цель проекта - предоставить руководству торговой сети «Соседушка» инструмент для комплексного анализа ключевых показателей продаж. Отчет решает основные бизнес-вопросы: определение динамики выручки и зон роста, выявление наиболее и наименее эффективных торговых точек, оценка реального влияния карт лояльности на чек, а также анализ сезонных колебаний спроса для оптимизации товарных запасов.
2. Данные
В основе отчета лежит массив данных об объеме порядка 80 тысяч транзакций за 2 года работы сети. Структура данных построена по классической схеме «звезда», где центральной таблицей является факт продаж (fact_sales), связанный с четырьмя справочниками: товары (dim_products), магазины (dim_stores), клиенты (dim_customers) и поставщики (dim_suppliers).
3. Что сделано
В ходе реализации проекта выполнен полный цикл обработки и визуализации данных:
Чистка и трансформация данных в Power Query, включая обработку типов данных и построение справочника дат dim_calendar.
Проектирование модели данных «звезда» с установкой связей типа «один-ко-многим».
Расчет ключевых бизнес-метрик на языке DAX (выручка, количество чеков, средний чек, вычисления YoY %, динамика YTD, средний чек с картой и без карты).
Разработка двустраничного интерактивного дашборда в Power BI («Обзор» и «Детали») с внедрением фильтров, срезов и карточек показателей.

4. Выводы по данным
Динамика и рост: Выручка сети показывает стабильный положительный тренд год к году, достигая пикового прироста YoY до 17% в весенние месяцы, однако в конце года наблюдается замедление темпов роста.
Эффективность магазинов: Лидерами по выручке являются магазины с ID 1, 7 и 17, каждый из которых преодолел отметку в 2,1 млн рублей, в то время как отстающие точки (ID 4, 5, 10, 19) генерируют всего около 0,5 млн рублей выручки, требуя аудита ассортимента и проходимости.
Карты лояльности: Средний чек клиентов без карты лояльности составляет 975,91 рублей, что немного превышает средний чек держателей карт (947,85 рублей) — это указывает на необходимость пересмотра условий программы лояльности для стимулирования кросс-продаж.
Сезонность: Главный сезонный провал происходит в феврале каждого года, когда выручка опускается до минимальной отметки в 0,8 млн рублей, тогда как весенне-летние месяцы и декабрь дают наибольшие пики продаж.
5. Инструменты
В рамках работы были использованы: Power BI Desktop, Power Query, DAX.
